## Things I confirmed are already in good shape

- Compose production: database has no published port; `app` non-root with `cap_drop: ALL` and `no-new-privileges`; migrations never run on app start; project name separates production volumes from development; log rotation set.
- Secrets: `.env*` is git-ignored and Docker-ignored (only `.env.example` is tracked, with placeholder values); `prisma/data`, `backups`, `DEV_ACCOUNTS.md` are ignored. No tracked key/pem/.env files found (`git ls-files` check).
- Passwords: scrypt with constant-time comparison; sessions store only a token hash; deactivated users lose access at once; generic login errors; audit trail is append-only.
- Health response never echoes driver errors.
- Production error pages show only a digest reference (Next production mode, `src/app/(app)/error.tsx`).
- No file upload surface exists, so no upload validation risk today.
